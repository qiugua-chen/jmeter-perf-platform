# 截图捕获清单（首次部署后补图）

README「界面速览」节预留了 4 张图的引用位（注释形式）。按下表捕获后：
1. 图片存入 `docs/images/`（本目录，`.gitkeep` 仅为占位，放图后可删）
2. 回 README「界面速览」取消对应行的注释

| 文件 | 内容 | 捕获步骤 |
|---|---|---|
| `build-parameters.png` | Build with Parameters 三级级联展开态 | 任务页 → Build with Parameters → 选 project=demo-shop → 等 script 级联刷新出 demo-shop.jmx、csvFile 刷新出 users.csv → 截图（三个下拉框同框） |
| `result-kpi.png` | 报告中心 KPI 查看页 | 完成一次 demo 构建 → 构建页 → 工作区 → 打开 result-kpi.html → 截图（统计表 + 标题区） |
| `error-details.png` | 报告中心错误明细 | 同次构建打开 errors.html → 截图（分组表 + 样本列） |
| `sync-console.png` | 发布同步成功控制台尾部 | 触发 perf-scripts-sync → 控制台拉到底 → 截图（含 `.sync-version` 行与 Finished: SUCCESS） |

## 要求

- PNG 格式，单张 ≤500KB；浏览器缩放 100%；宽度建议 ≤1400px（README 排版友好）
- **入库前打码**：内网地址、真实项目名/域名、凭据痕迹——沿用仓库脱敏标准
- 图片与文字互补：截图展示"长什么样"，操作步骤仍以文档文字为准
